# 🌀 Just An Create Mod Addons

## Mod Overview
Welcome to **Just An Create Mod Addons** — the chaotic smoothie of *every* Create addon I could find on Modrinth and CurseForge! 🍹  

If it spins, whirls, crushes, or explodes with gears… it’s probably in here. This mod packs together a buffet of Create-based addons — all mixed into one questionable masterpiece.  

Think of it like a **Create Addon Soup** — flavorful, slightly overpowered, and definitely made by someone who doesn’t know when to stop adding ingredients. 😅  

---

## ⚙️ Dependencies
To keep the gears turning and your world from exploding, you’ll need these:  

1. [**Create**](https://www.curseforge.com/minecraft/mc-mods/create)  
2. [**Create: Dragon Plus**](https://www.curseforge.com/minecraft/mc-mods/create-dragon-plus) *(required because Create Enchantment Industry loves dragons, apparently)*  
3. [**Create Enchantment Industry**](https://www.curseforge.com/minecraft/mc-mods/create-enchantment-industry)  
4. [**Create Crafts & Additions**](https://www.curseforge.com/minecraft/mc-mods/createaddition)
